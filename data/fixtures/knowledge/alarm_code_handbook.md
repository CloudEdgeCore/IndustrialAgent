# 报警代码手册

## 主轴与冷却类（CNC）

- **E101 主轴过载**（critical）：主轴负载超过额定值 120%。可能原因：切削参数过大、刀具磨损、材料硬度过高。
- **E102 主轴温度过高**（critical）：主轴温度超过 85℃。可能原因：冷却系统效率下降、冷却液不足或过滤器堵塞、主轴轴承磨损、温度传感器漂移。
- **E103 冷却系统压力异常**（warning）：冷却液压力偏离正常范围。可能原因：冷却泵故障、管路泄漏、过滤器堵塞。

## 液压类（注塑机）

- **E201 液压压力异常**（warning）：液压系统压力波动超出允许范围。可能原因：液压阀卡滞、油路泄漏、液压泵磨损。
- **E202 液压油温过高**（warning）：液压油温度超过 60℃。可能原因：冷却器堵塞、连续高负载运行、油量不足。

## 驱动与电气类

- **E301 伺服驱动器故障**（critical）：伺服驱动器报故障，轴运动停止。可能原因：驱动器过流、编码器信号异常、动力线接触不良。
- **E401 气压不足**（info）：气源压力低于 0.5 MPa。可能原因：空压机输出不足、管路泄漏、气源阀门未全开。
- **E501 振动超限**（warning）：设备振动超过 5 mm/s。可能原因：轴承磨损、动平衡失调、地脚螺栓松动。
- **E601 电机过流**（critical）：主电机电流超过额定值。可能原因：负载异常、电机绕组问题、供电电压波动。
