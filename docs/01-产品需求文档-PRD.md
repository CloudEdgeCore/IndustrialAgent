# 工业设备智能诊断与质量分析 Agent 平台
## 产品需求文档 PRD

**项目定位**：面向制造企业设备、工艺、质量场景的工业 AI Agent 平台。  
**项目目标**：让工程师通过自然语言完成设备故障诊断、工艺异常分析、质量问题溯源、工业知识检索与分析报告生成。  
**适用场景**：算法工程师 / AI Agent 开发岗位作品集、工业 AI Demo、企业 PoC。

---

## 1. 产品背景

传统制造场景中，设备报警、工艺异常和质量问题通常分散在多套系统中：

- 设备运行数据在 MES / SCADA / IoT 系统；
- 工艺参数分散在数据库或 CSV；
- 质量检测数据在 QMS；
- 设备说明书、SOP、维修记录以 PDF / Word / Excel 存在；
- 工程师依赖经验人工判断，问题定位效率低。

本项目通过 AI Agent 将结构化数据、时序数据和工业知识统一起来，形成一个可交互、可分析、可追溯的工业智能助手。

---

## 2. 产品目标

### 2.1 核心目标

1. 支持设备故障智能诊断。
2. 支持工艺异常分析。
3. 支持质量问题追溯。
4. 支持工业知识库问答。
5. 支持自动生成诊断 / 分析报告。
6. 支持多 Agent 协同完成复杂工业任务。

### 2.2 非目标

MVP 阶段暂不实现：

- PLC 实时控制；
- 自动修改生产设备参数；
- 真正替代 MES / SCADA / QMS；
- 复杂数字孪生 3D 仿真；
- 高风险工业控制闭环。

## 4. 核心业务场景

### 场景 A：设备故障诊断

用户输入：

> 3 号设备主轴温度连续 20 分钟超过 85℃，同时出现 E102 报警，帮我分析原因。

系统执行：

1. 识别为“设备故障诊断”任务；
2. 查询设备实时 / 历史运行数据；
3. 查询 E102 报警说明；
4. 查询历史相似故障；
5. 检索设备手册和维修 SOP；
6. 输出可能原因、证据、排查顺序和风险等级。

---

### 场景 B：质量问题溯源

用户输入：

> 最近 3 天 A 产品不良率为什么从 1.8% 升到 4.6%？

系统执行：

1. 查询质量检测数据；
2. 对比设备、班次、批次、工艺参数；
3. 找出异常变量；
4. 调用统计分析工具；
5. 关联历史相似质量问题；
6. 输出原因候选及证据。

---

### 场景 C：工艺异常分析

用户输入：

> 帮我分析昨天 2 号产线压力波动异常的原因。

系统：

- 查询压力时序数据；
- 对比正常基线；
- 检查上下游参数；
- 检查设备报警；
- 生成异常时间段及原因分析。

---

### 场景 D：工业知识问答

用户输入：

> E102 报警应该怎么处理？

系统基于：

- 设备说明书；
- SOP；
- 历史维修记录；
- 故障知识库；

返回带引用来源的回答。

## 6. Agent 设计

系统采用 1 个 Router Agent + 4 个专业 Agent。

### Router Agent

负责：

- 理解用户意图；
- 判断任务类型；
- 调度专业 Agent；
- 合并结果。

### Equipment Agent

负责：

- 设备故障分析；
- 报警解释；
- 设备运行数据查询；
- 历史故障匹配。

### Process Agent

负责：

- 工艺参数分析；
- 异常检测；
- 参数关联分析；
- 工艺知识检索。

### Quality Agent

负责：

- 不良率分析；
- 缺陷分布分析；
- 质量溯源；
- 统计分析。

### Report Agent

负责：

- 汇总分析结果；
- 生成结构化报告；
- 输出结论和证据。

## 9. AI 输出规范

AI 不能只给“结论”，必须输出：

1. 问题描述；
2. 数据范围；
3. 发现的异常；
4. 根因候选；
5. 每个根因对应证据；
6. 建议排查顺序；
7. 风险提示；
8. 数据来源。

示例：

```text
根因候选 1：主轴冷却系统效率下降
置信度：高

证据：
- 主轴温度过去 20 分钟持续 > 85℃
- 冷却液流量下降 18%
- 历史 E102 故障中 63% 与冷却系统相关

建议：
1. 检查冷却液液位
2. 检查冷却泵
3. 检查过滤器
```

## 11. 验收标准

### 功能验收

- 可以自然语言查询设备；
- Agent 能正确选择工具；
- 可以读取设备时序数据；
- 可以进行质量数据统计；
- 知识回答有引用来源；
- 可以生成完整诊断报告。

### AI 效果验收

典型测试集不少于 30 个问题。

要求：

- 意图分类准确率 ≥ 90%；
- SQL / Tool 调用成功率 ≥ 95%；
- RAG 引用正确率 ≥ 90%；
- 关键分析结果可追溯。

## 12. 简历表达

**项目名称**

基于大模型 Agent 的工业设备故障诊断与质量分析系统

**项目描述**

设计并开发面向制造业设备、工艺、质量场景的工业 AI Agent 平台，整合设备运行时序数据、工艺参数、质量检测数据及设备知识库，通过多 Agent 协同和 Tool Calling 实现设备故障诊断、工艺异常分析、质量问题溯源与自动报告生成。

**技术亮点**

- 多 Agent 任务编排；
- RAG 工业知识库；
- SQL + 时序数据查询；
- Python 数据分析工具；
- 异常检测；
- 根因分析；
- Evidence-based AI 输出；
- 工业数据可追溯。
