# 工业设备智能诊断与质量分析 Agent 平台
## 技术选型文档

## 1. 技术选型原则

这个项目的目标不是堆技术，而是：

- 能真正运行；
- 能展示工业 AI 能力；
- 能体现 Agent 工程能力；
- 面试时可以解释清楚；
- 一个人可以完成 MVP。

因此优先选择成熟、生态完整、开发效率高的技术。

## 3. 前端

### Next.js + TypeScript

选择原因：

- 企业 Web 应用生态成熟；
- 页面路由清晰；
- 适合 Dashboard；
- TypeScript 类型安全；
- 后续容易部署。

### shadcn/ui

选择原因：

- UI 现代；
- 可定制；
- 不像传统后台模板；
- 非常适合工业 AI 产品。

### ECharts

用于：

- 时序曲线；
- 质量趋势；
- Pareto；
- 散点图；
- 参数关联图；
- 告警统计。

---

## 4. 后端

### FastAPI

原因：

- Python AI 生态最好；
- 异步 API；
- Pydantic 数据模型；
- Swagger 自动文档；
- 和 LangGraph / Pandas / sklearn 集成简单。

---

## 5. Agent 框架

### 推荐：LangGraph

不建议只用 LangChain AgentExecutor。

原因：

工业分析不是简单：

```text
Question → LLM → Answer
```

而是：

```text
Question
→ Intent
→ Data Query
→ Analysis
→ Knowledge Search
→ Reasoning
→ Report
```

LangGraph 更适合：

- 有状态工作流；
- 多 Agent；
- 分支；
- Tool Calling；
- Retry；
- Human-in-the-loop。

---

## 6. LLM

Agent 层必须设计成模型可替换。

统一接口：

```text
LLM Provider
├── OpenAI-compatible API
├── Qwen
├── GLM
├── DeepSeek
└── Local Model
```

MVP 不建议自己训练大模型。

重点展示：

- Agent；
- Tool Calling；
- 工业数据分析；
- RAG。

---

## 7. 数据库

### PostgreSQL

存：

- 用户；
- 设备；
- 报警；
- 维修；
- 产品；
- 质量；
- Agent 会话；
- 报告。

### TimescaleDB

使用 PostgreSQL 扩展。

优势：

- 不需要再引入独立时序数据库；
- SQL 统一；
- 支持时间窗口；
- 支持连续聚合；
- 非常适合 Demo / 中小规模项目。

因此：

```text
PostgreSQL
+ TimescaleDB
+ pgvector
```

可以统一解决：

- 业务数据；
- 时序数据；
- 向量数据。

这是本项目最推荐的方案。

---

## 8. 向量数据库

### MVP 推荐 pgvector

而不是单独部署 Milvus / Qdrant。

原因：

- 架构简单；
- 部署成本低；
- 数据统一；
- 足够支撑项目 Demo。

后续数据量大再替换 Qdrant / Milvus。

---

## 9. 数据分析

基础：

- Pandas；
- NumPy；
- SciPy。

机器学习：

- scikit-learn。

MVP 算法：

- Isolation Forest：异常检测；
- Random Forest：质量影响因素；
- Pearson / Spearman：参数相关性；
- Z-score / IQR：异常值；
- PCA：多参数分析（可选）。

---

## 10. RAG

推荐流程：

```text
Docling
→ Markdown
→ Chunk
→ Embedding
→ pgvector
→ Hybrid Search
→ Rerank
→ LLM
```

Embedding 可使用任意兼容模型。

数据必须带 metadata。

---

- PDF；

- 复杂文档。

## 12. Redis

用途：

- Agent session；
- streaming state；
- cache；
- task status；
- distributed lock。

MVP 不需要复杂消息队列。

---

## 13. MinIO

存储：

- PDF；
- Word；
- Excel；
- 生成报告；
- 原始数据文件。

兼容 S3 API。

---

## 14. Observability

推荐 Langfuse。

```text

→ LLM

```

- Token；
- Latency；

- Tool；
- Error。

这部分非常适合面试展示。
