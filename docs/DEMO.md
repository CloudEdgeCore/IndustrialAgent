# Demo 剧本（Demo Script）

> 按 PRD §4 场景 A~D 逐步演示。全程约 10 分钟。

## 0. 准备（一次性）

```bash
docker compose up -d                    # 全栈：Nginx 80 / API 8000 / Web 3000(内网) / PG / Redis / MinIO
alembic -c apps/api/alembic.ini upgrade head
python -m data.simulator                # 重建演示数据（含场景注入，锚点=当前时间）
python -m tools.rag ingest              # 导入知识库（6 篇文档）
```

`.env` 中配置好 `LLM_API_KEY`（DashScope 或其他 OpenAI-compatible 端点）后即可开始。
浏览器打开 **http://localhost**（演示账号 **admin / admin123**）。

> 数据时效提示：分析窗口默认**锚定数据末尾**（`WINDOW_ANCHOR=data`），因此即使数据是几天前
> 生成的，"最近 24 小时 / 最近 3 天"仍落在数据时间轴上，场景可长期复现，**无需每次重新灌数**。
> 顶栏会显示「数据截至 …· 滞后 …」；若需数据看起来更新，执行 `python -m data.simulator` 重新生成。

## 1. Overview（30 秒）

打开 `/overview`：
- 顶栏「数据截至」标识（窗口锚点来源与数据滞后，> 24h 转告警色）；
- 顶部 KPI：设备总数 30 · 告警/停机 · A 产品近 3 天不良率（**3.5% vs 基线 1.8%**）· 报告数；
- **AI 风险摘要**：自动列出的风险项（E102 活跃报警 / 不良率升高 / 关注设备），每项带「立即分析」按钮；
- 设备健康度柱状图（最低 6 台）、不良率趋势（14 天，含基线虚线）、活跃报警与最近分析。

## 2. 场景 A：设备故障诊断（3 分钟）

1. 点击 AI 风险摘要中的 **E102** 项「立即分析」（或进入 `/ai`，用快捷问题「分析设备故障」）；
2. 观察右侧工作台：
   - **执行步骤流式出现**（SSE）：「已识别：设备故障诊断 → 查询报警信息 → 查询设备运行数据 → 执行数据分析 → 检索知识库 → 检索历史维修记录 → 生成报告」；
   - **Evidence 证据区**：每次工具调用的来源（postgres:sensor_readings / fixtures / document_chunks）与行数；
   - **诊断结果卡**：风险等级 + 结论摘要 + 「生成报告」链接。
3. 打开生成的报告（`/reports/{id}`）：根因候选（含置信度与逐条证据）、排查顺序、数据来源；可**导出 Markdown / 打印为 PDF**。

预期结论示例：EQ-003 主轴温度峰值 92℃（连续 >85℃ 超过 20 分钟）、冷却液流量跌破 15.3 L/min 阈值、E102 活跃——根因指向冷却系统效率下降（高置信度），与同设备的表面裂纹不良集中相互印证。

## 3. 场景 B：质量问题溯源（2 分钟）

1. `/ai` 输入：「最近 3 天 A 产品不良率为什么升高？」（或快捷问题「分析质量异常」）；
2. 观察 Quality Agent 调用：质检聚合（按缺陷类型/设备）→ Pareto → 时间序列关联（EQ-003 温度）→ 质量规范检索；
3. 结论应指出：不良集中于 **EQ-003（单台 15%）/ Night Shift / surface_crack**，整体近 3 天约 **3.5%**（基线 1.8%）；
4. 证据区会显示**数值证据校验**（`matched/checked` 可溯源比例）；若出现未溯源数值或子分析降级，会以琥珀色告警列出，供人工复核。
5. 同步对照 `/quality`：不良率趋势、缺陷 Pareto、不良设备分布（EQ-003 红色），并可从 AI 洞察卡一键跳转根因分析。

## 4. 场景 C：工艺异常分析（2 分钟）

1. `/ai` 输入：「分析昨天 2 号产线压力波动异常的原因。」；
2. Process Agent 拉取 LINE-2 压力与阀门开度序列 → 相关性分析 → 工艺规范检索；
3. 预期结论：15:20–16:05 压力波动放大（std 3.7×），与阀门开度相关系数 ≈0.93。

## 5. 场景 D：工业知识问答（1 分钟）

1. `/ai` 输入：「E102 报警应该怎么处理？」；
2. 预期回答引用《E102 主轴温度过高处理 SOP》（含步骤：液位 → 流量 → 冷却泵 → 过滤器 → 轴承振动）；
3. 也可在 `/knowledge` 直接检索：命中分块显示来源文档、章节与相关度。
